# PRD — BugLab
## Product
BugLab is a debugging practice platform where learners inspect realistic bugs, submit solutions, receive structured AI guidance, and review their attempts.
## Users
Learner, admin/evaluator.
## Goals
Provide searchable bugs, secure authentication, AI hints, file uploads, progress tracking, and an architecture that is easy to demonstrate in a technical viva.
## Functional requirements
- Register/login and OAuth starter.
- Browse/filter/order bugs.
- View a bug and submit a controlled solution.
- Upload supported bug-report files.
- Get AI hints through validated structured output.
- Stream AI output.
- Use RAG context and tool inspection.
- Store relational attempts and demonstrate Mongo documents.
- Provide monitoring/integration examples.
## Non-functional requirements
Security, input validation, rate limiting, responsive UI, testability, deployment portability, environment-based secrets.
